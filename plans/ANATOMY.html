กายวิภาคความจำ

ทุกชื่อ ทุกตัวเลข และทุกสถานะในหน้านี้อ่านออกมาจากโค้ดที่ผ่านเทสต์ 552 ข้อ ไม่ใช่ภาพร่างของสิ่งที่ตั้งใจจะทำ

01 · ภาพรวมห้องความจำสี่ห้อง กับทางเข้าสี่ทาง

หัวใจของดีไซน์คือ ความจำแต่ละชนิดเข้าถึง context คนละทาง และมีกฎคนละแบบ ไม่ใช่กองเดียวที่ค้นด้วยวิธีเดียว

02 · หน่วยเก็บความทรงจำหนึ่งชิ้นหน้าตาเป็นยังไง

13 ฟิลด์ แบ่งเป็น 5 กลุ่มที่มีหน้าที่ต่างกันชัดเจน — และการแยกกลุ่มพวกนี้คือสิ่งที่ทำให้ระบบทำงานถูก

03 · ต้นไม้ห้าชั้นของประสบการณ์ และจุดที่การนึกเริ่ม

ชั้นทั้งห้ามาจาก Conway & Pleydell-Pearce (2000) ที่พบว่าความจำอัตชีวประวัติของคน จัดเก็บเป็นลำดับชั้น และการนึกเริ่มที่ชั้นกลาง ไม่ใช่ที่ราก

04 · การจางบันไดห้าขั้น เรียงตาม “อะไรถูกทำลาย”

ไม่ได้เรียงตามว่าประหยัดกี่ไบต์ แต่เรียงตามว่า ขั้นนั้นฆ่าคำถามแบบไหน ตัวเลขทุกตัวมาจากการวัดจริง ไม่ใช่การเดา

05 · สองแกน“นึกไม่ออก” กับ “จำรายละเอียดไม่ได้” เป็นคนละเรื่อง

06 · เครื่องจักรสถานะสามวงจรที่ทำให้ทุกอย่างเดินได้

ทุกอย่างเป็น state machine เพราะ นับก้าวได้ · ตัดได้ · อธิบายได้ · และปล่อยให้ agent เลือกได้อย่างปลอดภัย (transition มีจำกัดและถูกตรวจทุกอัน)

การนึก — RecallMachine

ความตั้งใจ — TriggerRegistry

การนอน — ConsolidationMachine

07 · ค่าที่ตั้งไว้ปุ่มทุกปุ่มในระบบ

ทั้งหมดนี้เป็นค่า calibration ที่ยังตั้งมือ ต้อง tune บน dev seed เท่านั้น ไม่ใช่ความจริงที่ค้นพบ

ค่าตอนนี้ควบคุมอะไรตั้งผิดแล้วเกิดอะไร
dim256ขนาดเวกเตอร์ต่อความทรงจำเล็กไป = การประมาณมุมพัง (บิต = ขนาดตัวอย่าง)
MAX_CHILDREN12ลูกต่อ node ก่อนถูกแตก = กว้าง vs ลึกสูงไป = เดินเข้าผิดกอง (วัดได้ 10–20%) · ต่ำไป = ลึกจนไม่คุ้ม
beam4ดูลูกกี่ตัวต่อชั้นแคบไป = พลาดของที่เย็น
MIN_REPEATS4ทำซ้ำกี่ครั้งถึงนับเป็นทักษะต่ำไป = เรื่องบังเอิญกลายเป็นนิสัย
COHERENCE0.55ต้องเหมือนกันแค่ไหน (หักหัวข้อแม่ออกแล้ว)ต่ำไป = กองงานสะเปะสะปะกลายเป็นบุคลิก
CORE_REPEATS12ซ้ำกี่ครั้งถึงเลื่อนเป็นตัวตนต่ำไป = ตัวตนเปลี่ยนง่ายเกิน
CORE_SPAN200ต้องเป็นจริงมานานแค่ไหนไม่มีข้อนี้ = ทำ 50 ครั้งในสัปดาห์เดียวกลายเป็นนิสัย ทั้งที่มันคือโปรเจกต์
COUNTER_FLOOR0.70จางแค่ไหนถึงไม่ให้ไปดึงแก่นของแม่สูงไป = ความทรงจำที่เพี้ยนแล้วไปบิดสรุปของกลุ่ม
STRENGTH_WEIGHT0.15ความสดมีน้ำหนักแค่ไหนเทียบความตรงสูงไป = นึกถึงแต่เรื่องล่าสุดไม่ว่าถามอะไร (เคยพังตรงนี้: หาเจอ 3%)
USE_GAIN0.50นึกครั้งหนึ่งทำให้ตื้นขึ้นเท่าไหร่—
DECAY_PER_TICK0.999ไม่ใช้แล้วจมเร็วแค่ไหนครึ่งชีวิตราว 700 tick
MIN_RETRIEVAL_STRENGTH0.001พื้นของความตื้นต้องมากกว่า 0 เสมอ — ลึกได้ หายไม่ได้

08 · กฎเหล็กข้อที่แตกแล้วดีไซน์แตกทั้งหมด

N-01

resolve(addr) ห้ามคืนค่าว่าง สำหรับที่อยู่ที่เคยถูกสร้าง ตลอดอายุของ agent — ทุกครั้งที่ความทรงจำจาง จะเขียน alias ชี้ไปตัวที่แทนมัน คนที่ถือที่อยู่เก่ายังใช้ได้ แค่ได้ของที่หยาบลง

N-02

engine ตัดสินใจจากเวกเตอร์เท่านั้น — ลบข้อความทั้งคลังทิ้ง เส้นทางการเดินต้องเหมือนเดิมทุกบิต มีเทสต์คุม

N-06

CORE และ TRIGGER ห้ามจางเด็ดขาด — ตัวตนไม่เลือนเพราะความจำเต็ม ความตั้งใจไม่หายเพราะที่ไม่พอ ถ้าตัวตนอย่างเดียวไม่พอกับ budget ระบบจะ error ไม่ยอมกัดกินตัวตนให้พอดี

N-08

ห้ามมี code path ที่ O(N) ต่อการนึกหนึ่งครั้ง — วัดด้วยจำนวนการเทียบเวกเตอร์ ไม่ใช่จำนวนก้าว เพราะเดิน 2 ก้าวแต่เทียบครบทุกชิ้น = ซ่อนการสแกน ไม่ได้เลี่ยง
